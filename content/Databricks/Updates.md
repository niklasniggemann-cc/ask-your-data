**[[Genie Code]]**
- **Scheduled tasks reach GA** (Sep 1) — Genie Code can now run a prompt on a recurring schedule; each run executes the prompt as a full Genie Code session and produces a continuable chat with the results, turning recurring analysis into an unattended background task. Create one by asking Genie Code in chat (e.g. "Every morning at 6 AM, summarize the status of my overnight jobs") or manually via the Scheduled tasks pane. Distinct from the Aug 27 "Genie Code as a Lakeflow Jobs task" (that's Genie Code running as a step inside an existing pipeline; this is Genie Code driving its own recurring schedule directly). Updates [[Genie Code]]. [Source](https://docs.databricks.com/aws/en/release-notes/product/2026/september) / [Source](https://docs.databricks.com/aws/en/genie-code/scheduled-tasks)

**[[AI Search]]**
- **Struct and map column support, plus filter-only queries** (Sep 2) — AI Search indexes can now index and filter on struct and map columns (e.g. `filters={"profile.age": 18, "attrs['voltage']": 9}`), and support filter-only queries that return rows matching a filter with no vector or keyword retrieval at all. Arrays/maps can't nest inside structs; maps must be top-level with string keys and primitive values. Extends AI Search's filtering model beyond flat scalar columns. Updates [[AI Search]]. [Source](https://docs.databricks.com/aws/en/release-notes/product/2026/september) / [Source](https://docs.databricks.com/aws/en/ai-search/query-ai-search)

**Semantic Layer / [[Metric Views]]**
- **Metric views can now be shared via OpenSharing** (Beta, Sep 3) — metric views can be shared with Databricks users in other metastores or accounts using OpenSharing, the same cross-account/cross-metastore sharing mechanism already used for tables and Genie Spaces. Previously, metric views were explicitly excluded from OpenSharing. Extends governed semantic definitions (and by extension, what a Genie Agent or Genie One reasons over) across organizational boundaries, not just within one metastore. Updates [[Metric Views]]. [Source](https://docs.databricks.com/aws/en/release-notes/product/2026/september) / [Source](https://docs.databricks.com/aws/en/opensharing/create-share#metric-views)

**[[Unity Catalog]] / Unity AI Gateway**
- **Unity Gateway unified trace table reaches Beta** (Sep 1) — every MCP tool call now automatically emits an OpenTelemetry trace (tool name, arguments, errors, token counts, latency, session ID) into a single queryable table, no new instrumentation required. A Databricks internal case study paired this with Genie One (pointing it at the trace table and asking plain-English questions like "which tool errors recur the most") to find seven small MCP-server bugs costing an estimated $499K/year in wasted tokens and 12,000 eng-hours/year — found, quantified, and fixed in about an hour. The generalizable lesson: under-specified MCP tool signatures should absorb the range of reasonable inputs an LLM might send (e.g. coerce a list into a string) rather than crash on the first mismatch, since cryptic error tracebacks are what actually drive the expensive multi-turn retry loops. Updates [[Unity Catalog]]. [Source](https://www.databricks.com/blog/how-we-eliminated-1-million-year-wasted-ai-agent-spend-one-hour)
