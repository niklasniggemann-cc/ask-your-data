## Definition

Genie App Builder is [[Databricks]]' governed low-code ("vibe-coding") environment for building custom data apps on live, governed enterprise data. A user describes the desired application in plain language — or drops in a screenshot of a rough interface — and Genie App Builder generates a live build plan and a working app preview connected to real [[Unity Catalog]] data, with permissions and access controls built in from the start rather than bolted on afterward.

## Core Capabilities

- Natural-language or screenshot-driven app generation — describe the app or sketch its interface, get a live build plan and working preview back
- Runs on **App Spaces**, a dedicated governance boundary for apps built this way
- Backed by **Serverless Micro Apps**, a microVM runtime that scales to zero, keeping idle apps cost-free
- Apps read and write governed enterprise data through Unity Catalog rather than operating as disconnected prototypes

## Status

Announced at Data + AI Summit 2026 (June 16–17) alongside [[Genie ZeroOps]]; entered private preview shortly after. Still in private preview as of August 2026, with no GA date announced.
