- **Ana + Ontology** — TextQL's AI analyst agent (Ana) answers natural-language business questions by grounding itself in the **Ontology**, a semantic layer it builds automatically by reading schemas, query logs, and business logic across an organization's existing systems (no prior centralization required), then stores as a plain, version-controlled file tree synced bidirectionally with a Git remote on the *customer's own account* — a customer-owned-infrastructure framing distinct from every other vendor in this vault, whose semantic models live inside the vendor's own platform. **Fivetran + dbt Labs** (backfilled — first coverage in this vault; financial/deal terms dropped per scope, product substance kept)
- **Merger completed, "Agents Schema" open standard launched** (Jun 1, 2026) — Fivetran and dbt Labs completed their previously-announced merger, operating as one company. The real product news: **Agents Schema**, an open-source standard designating a single schema in a warehouse/lake as the shared, vendor-neutral context layer for AI agents — metric definitions, semantic models, dbt lineage, and business documentation stored as plain SQL tables, readable by any SQL-capable agent. A second entrant (alongside the already-logged Open Semantic Interchange) in the push toward portable, non-proprietary semantic context for AI, per analyst commentary (IDC's Devin Pratt: "an open standard the customer owns rather than one more lock-in").
